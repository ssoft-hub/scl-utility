# Std any

`<scl/utility/any/std_any.h>` читает объект, лежащий внутри `std::any`, тем же вызовом
`scl::any_cast`, каким пользуется вся остальная группа.

- Заголовок: `#include <scl/utility/any/std_any.h>`

## Обзор

Представление и аргумент называют только тот тип, с которым связаны. Поэтому
[`any_view`](any_view.md), [`any_arg`](any_arg.md) или
[`any_mutable_view`](any_mutable_view.md), связанные с `std::any`, ссылаются на сам
`std::any`: `type_name()` возвращает `"std::any"`, `any_cast<std::any>` возвращает этот же
объект, а приведение к любому другому типу не возвращает ничего.

Обратное направление живёт в этом заголовке - единственном в группе, который вообще называет
`std::any`. Он читает объект, который хранит `std::any`, специализируя
[`any_cast_traits`](any_cast.md) для `std::any`, и приведение, которое нигде не называет
`std::any`, эту специализацию не порождает - значит, за возможность не платит. Зонтичный
`<scl/utility/any.h>` подключает заголовок вместе со всей группой: ничего не стоит именно
приведение, а не подключение. Без RTTI заголовок пуст целиком: там `std::any` назвать нельзя.

## Возможности

- Доходит указателем до объекта, который хранит `std::any`; при несовпадении типа
  возвращается `nullptr`, исключение не выбрасывается.
- Доходит до него копией, константной ссылкой, а для неконстантного `std::any` и
  неконстантной ссылкой; при несовпадении типа выбрасывает `scl::bad_any_cast`. Контейнер
  без имени в месте вызова отдаёт свой объект перемещением.
- Отвергает `std::any` с квалификатором `volatile` на вызове: `std::any_cast` не принимает
  указателя на такой объект.
- Приведению, которое нигде не называет `std::any`, не стоит ничего.
- Существует только в сборках с RTTI, а форма со ссылкой - только там, где доступны
  исключения.

## Справочник по API

### Приведение

```cpp
std::any boxed{std::string{"Hello Any!"}};

scl::any_cast<std::string>(&boxed);        // std::string *, nullptr при несовпадении
scl::any_cast<std::string>(boxed);         // копия хранимой строки
scl::any_cast<std::string const &>(boxed); // хранимая строка, без копии
scl::any_cast<int>(&boxed);                // nullptr
scl::any_cast<int>(boxed);                 // выбрасывает scl::bad_any_cast
```

Форма с указателем возвращает `nullptr` и для нулевого указателя, и для пустого `std::any`, и
для `std::any`, хранящего объект другого типа. `std::any` владеет тем, что хранит, поэтому его
собственная константность доходит до хранимого объекта: неконстантный `std::any` возвращает
значение типа `T *`, константный - `T const *`, ровно как `std::any_cast`. Квалификация самого
запроса в сопоставлении не участвует, поэтому `any_cast<T>` и `any_cast<T const>` доходят до
одного и того же объекта.

Копирующая форма просит чтение, поэтому объявляется только для типа, который можно
скопировать с константного объекта. Это строже буквы `std::any_cast<T>(std::any &)`, где
предписано лишь конструирование из `U &`; libstdc++ требует и константную форму, и
приведение группы требует её для любого источника.

Форма со ссылкой объявлена только там, где
[`SCL_HAS_EXCEPTIONS`](../preprocessor/exceptions.md) равно `1`. При отключённых исключениях
остаётся форма с указателем, и о несовпадении типа она уже сообщает.

### Через представление

```cpp
std::any boxed{std::string{"Hello Any!"}};
scl::any_view const view{boxed};

scl::any_cast<std::string>(&view);    // nullptr: представление называет сам std::any
scl::any_cast<std::any const>(&view); // сам std::any
scl::any_cast<std::string>(&boxed);   // строку внутри std::any
```

Запись в хранимый объект идёт через `std::any`, который отдаёт представление:

```cpp
scl::any_mutable_view const over_any{boxed};
std::any_cast<std::string &>(*scl::any_cast<std::any>(&over_any)) += "!";
```

Цепочка [`any_switch`](any_switch.md) берёт `std::any` как обычный тип ветви: ветвь с этим
типом подходит самому `std::any`, а внутрь не заглядывает ни одна. Применяйте цепочку к тому,
что вернуло приведение по `std::any`.
