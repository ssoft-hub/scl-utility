# `SCL_INDETERMINATE`

Макрос `SCL_INDETERMINATE` записывается на переменной с автоматической продолжительностью хранения
или на параметре функции, память которых не читается до записи. Реализация тогда не обязана задавать
этой памяти ошибочное значение в C++26.

- Заголовок: `#include <scl/utility/attribute/indeterminate.h>`

```cpp
#define SCL_INDETERMINATE /* see below */
```

## Семантика

- **Без инициализатора:** переменная с автоматической продолжительностью хранения, объявленная
  без инициализатора, остаётся неинициализированной, во что бы ни раскрылся макрос. Инициализируется
  только то, что инициализирует конструктор по умолчанию.
- **Что сообщается компилятору:** память не читается до записи. Реализация задаёт такой переменной
  ошибочное значение в C++26, и чтение до первой записи является ошибочным поведением. Реализация
  может не задавать это значение под атрибутом `[[indeterminate]]`.
- **Без атрибута:** чтение до первой записи является неопределённым поведением до C++26 и ошибочным
  поведением в C++26.
- **Ложное обещание:** чтение такой памяти до записи является неопределённым поведением
  под атрибутом `[[indeterminate]]`.
- **Место:** макрос записывается перед определением переменной с автоматической продолжительностью
  хранения или перед параметром в первом объявлении функции. Программа некорректна, и компилятор
  не обязан сообщать об этом, если параметр объявлен с атрибутом в первом объявлении функции в одной
  единице трансляции и без него в первом объявлении в другой.

| Условие, первое совпавшее | Раскрытие |
|---|---|
| `__has_cpp_attribute(indeterminate)` (C++26), `indeterminate` не является макросом | `[[indeterminate]]` |
| ничего из перечисленного | пусто |

Макрос раскрывается в `[[indeterminate]]`, если `__has_cpp_attribute(indeterminate)` не равно `0`
и `indeterminate` не является макросом. GCC 13, Clang 22 и MSVC 19.44 сообщают значение `0` в C++20,
поэтому там макрос раскрывается в пустоту.

## Определения до заголовка

Определение макроса, сделанное до его заголовка, сохраняется только в виде одного из раскрытий ниже
для данного компилятора. Сборка с любым другим текстом завершается с ошибкой, как описано
на [странице группы](index.md#замена-макроса).

| Макрос | GCC | Clang, clang-cl | MSVC |
|---|---|---|---|
| `SCL_INDETERMINATE` | пусто | пусто | пусто |

## Примеры

Буфер, который заполняется цифра за цифрой и читается только там, где уже записан:

<!-- snippet: example/attribute/indeterminate/attribute_indeterminate_example.cpp indeterminate -->
```cpp
std::string reversed_decimal(unsigned value)
{
    SCL_INDETERMINATE
    char digits[std::numeric_limits<unsigned>::digits10 + 1];
    std::size_t count = 0;
    do
    {
        digits[count++] = static_cast<char>('0' + value % 10);
        value /= 10;
    } while (value != 0);
    return std::string(digits, count);
}
```
